# Project Outpost（末日营地）技术架构

> 配套设计文档见 `游戏介绍.md`。本文件描述代码层面的技术架构。

## 技术选型
- 引擎：Cocos Creator 3.8 + TypeScript（2D 项目）
- 目标平台：抖音小游戏（Cocos「构建发布 → 抖音小游戏」导出）
- 项目位置：`project_outpost/`（英文路径，避开中文路径在抖音/Cocos 构建时的兼容问题）

## 三条核心设计原则
1. 代码驱动：场景里只放一个挂 `GameRoot` 的空节点，地图 / 角色 / UI 全部用代码动态创建，几乎不依赖编辑器拖拽。
2. 逻辑与渲染分离：`core/` 是纯 TypeScript 模拟内核（不 import cc，可脱离引擎运行与测试）；`render/` 与 `ui/` 是 Cocos 适配层，只负责把内核状态画出来、把输入转成内核指令。
3. 容器平移缩放：通过移动 / 缩放 `WorldContainer` 节点实现地图平移缩放，避免 Cocos 多相机复杂度。

## 场景结构（编辑器里只需手动建一次）
```
Canvas
├── GameRoot        (空节点, 挂 GameRoot.ts, 全局入口)
├── WorldContainer  (平移/缩放此节点)
│   ├── MapGraphics (cc.Graphics, 画地形)
│   └── EntityLayer (角色/僵尸/建筑节点池)
└── HUDLayer        (固定 UI: 资源栏/建筑菜单/人口面板/时间栏)
```

## 目录结构
```
project_outpost/assets/scripts/
├── core/                 纯 TS 内核（无 cc 依赖）
│   ├── Types.ts          枚举与接口
│   ├── Config.ts         全部平衡数值
│   ├── GameMap.ts        100x100 瓦片地图 + 程序化生成
│   ├── Pathfinding.ts    网格 A*
│   ├── Entities.ts       幸存者/僵尸数据模型
│   ├── ResourceStore.ts  资源与上限
│   ├── Buildings.ts      建筑定义与建造工地
│   ├── World.ts          全局状态 + tick(dt) 驱动
│   ├── SaveManager.ts    存档序列化
│   └── systems/          JobSystem / MovementSystem / BuildSystem /
│                         CombatSystem / WaveSystem / PopulationSystem
├── render/               Cocos 适配层
│   ├── GameRoot.ts       cc.Component 入口
│   ├── MapRenderer.ts    地形渲染（视口裁剪）
│   ├── EntityRenderer.ts 实体节点池
│   └── InputController.ts触摸：平移/缩放/放建筑/选中
└── ui/
    └── HUD.ts            资源栏/建筑菜单/人口面板/时间栏/变速
```

## 数据流
```
GameRoot.update(dt)
  → 固定步长累加器
  → World.tick(scaledDt)
      → PopulationSystem → JobSystem → MovementSystem
      → BuildSystem → CombatSystem → WaveSystem → 资源生产
  → MapRenderer / EntityRenderer / HUD 只读 World 状态作画
InputController → 调用 World 指令方法（如 placeBuilding(type,col,row)）
```
约束：渲染层只读状态、绝不反向写状态；输入只通过 World 暴露的指令方法修改状态。

## 关键技术点
- 寻路：每个实体按需 A*，同一帧限制重算数量；僵尸潮后续可升级为 flow-field。
- 渲染性能：地形用单个 Graphics + 视口裁剪，仅在地图/视口变化时重画；实体用对象池复用节点。
- 模拟：固定步长 tick，支持暂停 / 1x / 2x / 3x；与渲染解耦，便于存档与回放。
- 存档：World 快照序列化为 JSON，存 `sys.localStorage`（Web 与抖音通用）。
