# 一、项目简介

Project Outpost 是一款像素风末日生存模拟经营游戏。

玩家作为末日营地领袖，需要带领幸存者建设基地、采集资源、安排职业、发展人口，并抵御不断增强的尸潮。

游戏采用俯视角 2D 视图。

整体玩法偏自动化管理。

玩家主要负责决策，而不是直接控制角色。

参考游戏：

* RimWorld
* Survive: Starvation & Infection
* They Are Billions
* Last War
