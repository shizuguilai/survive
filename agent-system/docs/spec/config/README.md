# 参数说明

`defaults.json` 是待调优的原型参数，不代表任何引擎已经读取它。所有以 SimMs/SimTicks 命名的量只用模拟时钟，以 WallMs 命名的量只供网络与观察者。

- 全局屏障、不追帧、不自动规则兜底、不共享私密上下文属于硬约束，不提供普通玩家开关。
- 初始2人，扩展样例10人；不是硬性人口上限。
- 视觉角度、距离和听觉相对衰减只是游戏设计参数。`world unit`在本原型中按一米的视觉比例建模，但旧瓦片数据迁移必须显式转换，不能把旧32像素直接当32米。
- 听觉环可由参考音量与阈值计算理想半径，受墙和噪声修正；不要独立写一个与公式不一致的“固定听觉半径”。340这一传播速度只作为理想参数，不宣称完整声学拟真。
- 语速用于文本声音事件的模拟时长。接TTS后按实际生成资产的对齐信息替换并锁入回放，不能在播放时重新生成另一种长度。
- 所有参数变更要提高config版本或记录hash。回放必须使用生成时参数。
- 真模型配置未提供：初始模式UNCONFIGURED，不能自动以Mock启动后假装已接入。

服务端环境变量样例只用于列明所需配置，不能填入真实key后提交Git。
