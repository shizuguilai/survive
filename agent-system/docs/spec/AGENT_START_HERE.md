版本：1.0.0 · 2026-09-23  
用途：交给后续编码 Agent 的设计与实施约束包。**这是待实施规格，不是已经完成的游戏。**

## 0. 唯一目标与最高优先级决定

唯一目标仓库：`git@github.com:shizuguilai/survive.git`。

本次远端核对：`main` = `60f5d7eb33860484065a3f98afc5693e9e69c337`，提交时间 `2026-06-03T01:28:21Z`。`package.json` 声明 Cocos Creator **3.8.6**。这是当前旧实现的基线，不是目标引擎版本。目标采用 **LayaAir 3.x + TypeScript 原生 3D**；具体 LayaAir/IDE 小版本由 T00/T01 实测锁定，禁止猜测或套用其他项目版本。

**用户最新决定覆盖此前“模型思考时身体和世界继续运动”的方案：只要任何居民进入需等待大模型的认知事务，整个世界的模拟时间暂停，所有居民和环境都不推进。等本轮所需决策完成并统一生效，再恢复模拟。**

暂停的是世界模拟，不是 JavaScript 事件循环、HTTP 请求、重试、存储、观察者界面或摄像机。角色上下文只使用模拟时间，永远不包含这次 API 等了多少真实秒。

## 1. 必须保留的产品意图

1. 玩家是规划者：划居住区、种植区、作业/仓储区，设置发展目标与资源边界；不逐个放建筑，不给居民分配固定职业。
2. 每名居民都拥有独立的大模型认知循环、性格、技能、个人目标、关系、记忆和承诺。共享模型服务不等于共享上下文。不得用中央模型扮演所有人后称之为独立认知。
3. 所有目标选择、主动转向、合作接受/拒绝和重要计划改变都由对应居民的真实模型决策。工程执行已批准的动作、感官过滤、世界规则、格式校验；不偷偷代替居民决定工作。
4. 角色只拥有有限感官和私人记忆。视觉扇形、遮挡、听力、语音清晰度、身体刺激都由工程实现；不能把世界真相先发给模型再让它“假装不知道”。
5. “下意识”是上一轮模型批准的可执行计划和条件预案，不是后台另一个会自行分配工作的规则大脑。
6. 观察者可开关所选居民的视野扇形、听觉参考环、实际感知线索和最后已知位置；这个开关不得改变感知结果或模型输入。
7. 提供交互式现场模拟和先计算后播放的观察回放。回放不重新调用模型，按模拟时间消除 API 等待空档；播放仍保留真实行动、说话和主动等待的时长。
8. 不以节约费用为理由取消任何居民的大模型认知。仍需工程限流、取消和错误处理，目的是可运行、可恢复，不是用 Mock 伪造真人自治。

## 2. 阅读顺序：不要一次性吞全部文件

| 文件 | 用途 |
|---|---|
| `SYSTEM_DESIGN.md` | 产品范围、分层、区域规划、合作与迁移原则 |
| `TIME_BARRIER_PROTOCOL.md` | 最重要：三种时钟、全局屏障、批次提交、对话、失败恢复 |
| `PERCEPTION_AND_MEMORY.md` | 感官、知识隔离、感官可视化、私人记忆 |
| `LLM_CONTRACT.md` | 调用边界、动作白名单、输入输出、模型错误处理 |
| `IMPLEMENTATION_PLAN.md` + `task-board.json` | 按依赖逐步落地、文件落点、完成标准 |
| `ACCEPTANCE_TESTS.md` | 可执行的测试场景与通过条件 |

遇到冲突：用户最新指令 > 本文件硬约束 > 时间协议 > 其他设计文件 > 示例。发现冲突先记录并修订，禁止擅自回到异步推进世界的旧方案。

## 4. 第一条垂直闭环

先做两名居民、两棵树、一堵墙的一次相遇：

`有限感知 → 唤醒 → 冻结全世界 → 各自真实模型决策 → 原子提交意图 → 世界推进 → 实际发声 → 对方听见 → 再次冻结 → 回应 → 回放`

第一条闭环没通过之前，不先堆人口、复杂建筑、尸潮和美术。Mock 可帮助写自动化测试，但不能用它交付“已经接入大模型”。

## 5. 每个任务的交付记录

`task-board.json` 全部任务初始为未开始。每个任务分别记录：变更文件、提交号（如确有）、运行命令、退出码、结果、证据文件、后台配置状态、阻塞原因。

缺 API key、缺模型访问权限或缺 Laya IDE 时，登记阻塞并继续无依赖任务。API 失败时保持暂停，不能自动生成一个规则决定冒充模型回复。
