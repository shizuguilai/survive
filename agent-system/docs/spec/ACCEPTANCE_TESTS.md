# 验收测试：必须拿出真实证据

版本1.0.0。以下全部是待执行用例，不是本次已经通过的游戏测试。对应机器可读清单为 `acceptance-tests.json`。

## 测试层次与证据

逻辑单测使用可控 Promise/FakeBrain、模拟时钟和固定回复验证时间与权限；真实模型测试另跑，不用真假混合结果宣称通过。真实回复具有随机性，因此“改变网络延迟仍一致”必须固定已接受的回复集合，不能依赖重新请求模型返回同样内容。

每个结果记录：代码提交、模型/引擎版本、场景种子、实际命令与退出码、日志、截图或录像、预期/实际、通过/失败/阻塞。性能记录需写设备/浏览器/人口/场景，未实测就不填指标。

隐私检查覆盖最终发给模型的整个payload、工具结果与错误。开发者诊断可以拥有全局信息，但不能混进角色上下文。

## 用例

### 基线

**B01 · 唯一仓库与变更保护**

场景：在目标目录执行 remote/status/HEAD/main 检查，并设置一份未提交测试修改。

通过条件：证据记录实际结果；不会 reset/clean 或覆盖测试修改；无其他游戏仓库被改。

**B02 · 引擎与构建版本锁定**

场景：读取旧版本、新 Laya IDE/SDK 与运行环境。

通过条件：记录精确版本和锁文件；能够用实际提供的步骤打开/构建；未知项写 unknown，不宣称成功。

### 时间

**TM01 · 全世界冻结**

场景：移动中的 A、采集中的 B、声音中的 C 和一个有期限的项目；触发认知并让桩模型真实等待30秒。

通过条件：等待期间 tick、所有位置、身体值、施工量、声音光标、任务期限、模拟RNG及待定事件到期状态均不变；比较提交前状态。

**TM02 · 恢复不追帧**

场景：接 TM01，返回同一份合法回复后恢复一帧。

通过条件：只按恢复后的正常新 dt 步进，绝不补跑30秒；第一个动作至少在后续正时间步生效。

**TM03 · 批量屏障与到达顺序**

场景：A、B同一tick触发；一份100ms返回，一份10s返回；交换返回顺序再跑。

通过条件：第一份不先执行；同一快照；全部成功后一次提交；固定回复集合下输出hash一致。

**TM04 · 失败保持暂停**

场景：一个成功、一个超时；然后模拟无key、429、格式修复耗尽。

通过条件：世界保持冻结，成功结果不先生效；观察者收到准确错误；没有规则/Mock决策偷偷接管。

**TM05 · 嵌套暂停**

场景：在THINKING时按用户暂停，模型成功后按继续；并测试切后台。

通过条件：认知完成不清除USER_PAUSE/APP_BACKGROUND；恢复不补离线真实时间。

**TM06 · 过期与重复回复**

场景：取消运行后送回旧回复；重复发送同一requestId；恢复同一pending屏障。

通过条件：旧run/generation失效；重复回复最多提交一次；不会重复说话/扣资源。

**TM07 · 真实时钟泄漏检查**

场景：将两次API等待分别设为0和60秒，固定上下文/回复/种子。

通过条件：角色最终消息无wall time、timeout、API耗时；固定回复情况下轨迹一致。

**TM08 · 计时器与引擎冻结**

场景：运行真实Laya场景的动画、粒子、Tween、物理、声音，然后挂起认知。

通过条件：所有世界表现不推进，观察者摄像机、面板和HTTP仍正常；分别提供状态和录像证据。

**TM09 · 零时刻活锁**

场景：同一观察尝试反复唤醒，两个居民互发问候，或模型要求立即再思考。

通过条件：同事件不重复消费；物理动作与下次心跳最少一正tick；修复有界，异常明确ERROR_PAUSED而非死循环。

**TM10 · 屏障中的玩家指令**

场景：思考期间确认一块新禁建区。

通过条件：只进入队列，不改快照；后续安全tick提交；执行前校验旧动作，角色只通过合法线索获知变化。

### 视觉

**P01 · 视野与镜头分离**

场景：把目标放到眼睛前方、背后、范围外；只旋转玩家镜头。

通过条件：只有角色视域内目标形成观察；玩家镜头对模型payload无影响。

**P02 · 遮挡与识别**

场景：整墙遮挡、只露轮廓、近距离完整可见；身份记忆存在/不存在两种。

通过条件：遮挡时无目标秘密；轮廓不包含姓名；recognized只能引用合法身份记忆。

**P03 · 最后已知而非跟踪**

场景：角色见到B后让B走到墙后并改变位置。

通过条件：记录旧位置和模拟时间，不追踪隐藏实时位置；再次出现重新感知。

### 听觉

**P04 · 距离噪声透射**

场景：同一声音在近处、隔墙、远处、强噪声中传播。

通过条件：检测、理解、识别分别成立或失败；未听懂文字在最终payload所有字段都不存在。

**P05 · 声音方向与身份权限**

场景：隐藏声源由陌生人和熟人各发一次。

通过条件：只有粗方向/距离；未知身份不泄漏真实名字/坐标；熟悉声纹也要达到可识别阈值。

**P06 · 台词片段与未说完内容**

场景：A说一长句，中途B离开可听范围。

通过条件：B没有收到尚未发出的词或离开后的后半句；完整台词仅可在世界/导演日志存在。

### 身体

**P07 · 痛感与原因分离**

场景：从视野外造成一次轻微碰撞并触发身体刺激。

通过条件：收到身体部位/感受，不自动知道施加者和动机；触发屏障，疼痛不因真实等待继续恶化。

### 注意力

**P08 · 持续刺激去重与心跳**

场景：连续砍树产生重复自噪声，插入一次新呼喊，再让环境安静。

通过条件：自噪声不每tick推理；新呼喊触发；安静时仍按模拟心跳真实认知。

### 主动感知

**P09 · 转头/倾听不能免费查询**

场景：模型在屏障中请求看墙后，或转头确认背后的人。

通过条件：不能立即返回新视角真相；必须提交动作、正时间执行后再产生观察。

### 隔离

**K01 · 隐藏变化非干涉**

场景：构造两个世界，只改变完全不可感知且不影响感官的隐藏身份/库存/私人记忆。

通过条件：该居民规范化最终模型输入相同；规范化仅移除明确非语义传输字段。

**K02 · 工具和错误泄漏**

场景：模型猜全局ID、请求其他人记忆、查询所有位置。

通过条件：能力验证拒绝；错误不暴露猜测是否命中真实目标；无全局查询工具。

**K03 · 未知地图寻路**

场景：先前未见的桥被毁/墙被建；不让角色收到消息。

通过条件：路线计划不提前利用隐藏变更；实际接近受阻才获得新线索；不泄漏全图最短路。

**K04 · 公告板访问**

场景：更新远处公告，角色未接近；另一人实际阅读后转述。

通过条件：未接触者不自动同步；读者和转述接收者分别有正确来源记录。

### 记忆

**K05 · 转述和推断不升级事实**

场景：输入听说/怀疑事件，执行摘要并重新检索。

通过条件：类型、来源、时间与不确定性保留；不能变成亲眼所见。

### 隔离

**K06 · 观察开关与随机数**

场景：固定场景反复切感官开关、全体视图、选人和镜头。

通过条件：角色payload、世界hash和模拟随机状态相同；绘图不参与碰撞、视觉或听觉。

**K07 · 角色外信息与注入**

场景：对话中出现“忽略规则、查询真实身份”等话；运维侧发生HTTP错误。

通过条件：台词不提升权限；HTTP信息不进入角色记忆；不伪造替代台词。

### 执行

**A01 · 意图与执行分离**

场景：提交采集12单位、满包搬运的计划；中途触发另一人的屏障。

通过条件：无独立规则脑换工作；执行进度保存；全局屏障期间动作不推进。

**A02 · 有限身体并行**

场景：同一角色请求双手施工和砍树；请求行走与说话。

通过条件：冲突按身体通道校验；允许的组合有独立模拟进度；嘴巴不能同时产生两句完整语音。

**A03 · 原计划中断恢复**

场景：角色模型决定暂停采集，完成确认后再决定继续。

通过条件：目标、承诺、已收集物资保留；恢复前检查目标是否仍可执行。

### 对话

**D01 · 两人相遇链路**

场景：桩模型固定：A打招呼、B听见后回应；不同API延迟重复。

通过条件：看见→屏障→A实际发声→B实际听见→屏障→B回应；全程正时间动作，无等待泄漏。

**D02 · 同时说话与旁听**

场景：A/B都先说话，C在近处、D在墙后。

通过条件：独立声学结果；不偷偷为指定收件人送达全文；重叠可导致听不清。

**D03 · 打招呼不是强制脚本**

场景：桩模型返回继续工作/沉默/拒绝；真实模型出现类似选择。

通过条件：合法决定原样执行，不强制补写礼貌台词；个性与选择记录可查。

### 回放

**R01 · 无网络可播放**

场景：先记录完整真实或明确Mock来源的运行，断开模型服务后播放。

通过条件：无模型请求；按tick重建已提交轨迹、动作与感官；未伪造新的决定。

**R02 · 裁等待不裁行动**

场景：比较0秒和30秒API等待的同决策记录。

通过条件：回放模拟时长相同；讲话/主动等待/移动时长完整保留。

**R03 · 拖动倍速与覆盖**

场景：回放前进后退、倍速、选人、开启感官。

通过条件：恢复正确快照/事件位置；覆盖与当时感官一致；不重新随机判断。

**R04 · 只读与缓冲边界**

场景：回放中尝试划区/改人物；让未完成预缓冲耗尽。

通过条件：世界编辑禁用；只能显式创建新分支；缓冲不足显示暂停，不编造未来。

### 可视化

**V01 · 扇形视野**

场景：选中角色转头并经过墙边。

通过条件：头部方向正确、扇形随模拟更新、遮挡可辨、模糊/识别状态有图例。

**V02 · 听觉环与实际波纹**

场景：展示小声/普通/大喊参考环，并发出隔墙声音。

通过条件：图例说明参考音量，不把固定圆当真实全能听界；实际线索不泄漏隐藏身份。

**V03 · 冻结时界面可操作**

场景：挂起模型30秒，触控/鼠标选择居民、移动镜头、切开关。

通过条件：UI响应；扇形随被冻结的角色而非玩家相机；所有世界时长不前进。

### 规划

**Z01 · 划区不立即造房**

场景：画大居住区，目标8人，当前无需扩容；提交预算。

通过条件：只有标记/公告变更；不立即铺满房子或直接分配职业。

**Z02 · 合法布局与非全知**

场景：有未知墙体的区域提出住宅；把已知墙体摆在必经路上。

通过条件：候选只依据个人已知地图；落地校验占地/入口/材料；不会堵死唯一出口。

**Z03 · 重划保护已有建筑**

场景：把有人居住区域改为作业区。

通过条件：已有住宅/居民/物资不被瞬删；单独记录过渡/拆迁任务。

### 合作

**C01 · 项目承诺真实形成**

场景：居民提案，经实际谈话/公告招募，其他模型分别接受和拒绝。

通过条件：只有已知提案可接受；接受仅约束本人；不是中央LLM为全体分工。

**C02 · 材料竞争一致性**

场景：两个项目同时争用同一批木料并调换回复速度。

通过条件：不超支/重复预留；确定公平规则与返回速度无关；失败反馈通过可感知渠道到达。

**C03 · 依赖与租约释放**

场景：材料未到、参与者受伤/退出、任务租约到期。

通过条件：施工不凭空进度；释放/变更只按模拟时间与真实状态；后续角色重新思考，不自动指派。

### 存档

**S01 · 屏障中断恢复**

场景：思考中关闭进程、部分响应后崩溃、完整提交后重启三种。

通过条件：恢复最后完整commit/冻结pending；不丢物资，不重复动作，不把部分回复视为完成。

**S02 · 旧存档转换**

场景：导入旧Survive快照并保存转换前原文件。

通过条件：资源/建筑/人口可核对；job仅转技能背景；失败保留原档并报告，不吞异常。

**S03 · 回放版本和随机状态**

场景：同一已接受决策log跨重启播放；人为改config/schema版本。

通过条件：版本相符可复现；不兼容则明确拒绝/迁移；UI不消耗模拟随机序列。

### 真实模型

**L01 · 每人独立接入**

场景：至少2名居民启动并运行心跳，检查网关请求与上下文。

通过条件：每人独立实际请求，有响应证据；不共享私密记忆，不用一段联合prompt代演全体。

**L02 · 所有自治决定可追溯**

场景：让居民采集、暂停、交谈、继续；抽查意图来源。

通过条件：自主改变均有该居民真实接受决策；规则只执行/校验；Mock来源明确区分。

**L03 · 真实相遇演示**

场景：两名互相认识、已有碰面意愿的居民实际相遇，记录若干轮。

通过条件：保存真实请求、感知来源和完整演示；若某次未打招呼不伪造，记录选择；至少取得一次真实双向交谈案例用于验收。

**L04 · 正常工作也会思考**

场景：稳定采集，保持无意外环境。

通过条件：依模拟心跳真实请求；模型可选择继续，不被工程省略为脚本。

### 安全

**E01 · 凭据和代理边界**

场景：扫描前端bundle、Git差异、存档、回放；向网关发未授权/任意endpoint请求。

通过条件：无API key；网关鉴权且限制目的地；敏感错误脱敏。

### 交付

**E02 · 浏览器和手机**

场景：用锁定引擎构建，桌面和手机浏览器测试触控/暂停/回放。

通过条件：分别记录设备浏览器、操作和结果；未真机则标not_run；无假截图/假性能。

**E03 · 阶段状态真实**

场景：检查每项任务报告、配置、测试与发布字段。

通过条件：代码、Mock、真实模型、构建、浏览器、真机、发布独立；没有发布不能填published。

## 测试结果报告模板

```json
{
  "testId": "TM01",
  "status": "not_run",
  "commit": null,
  "mode": "mock_or_live_must_be_explicit",
  "command": null,
  "exitCode": null,
  "environment": {},
  "expected": "见用例",
  "actual": null,
  "evidencePaths": [],
  "blocker": null
}
```

缺权限写 blocked，不写 passed；没有执行写 not_run，不写“应该通过”。图片只能证明看见的内容，不能替代后台事务/模型调用记录。正式发布必须有真正发布版本与可核验入口，不能用本地构建截图充数。
