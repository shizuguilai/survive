# 相遇和讲话触发 v0.3.2

同一居民从进入视野到离开，只在进入时请求一次认知。距离、方向、模糊变清晰、认出姓名、穿戴变化和最终离开仍记录私人观察，但不再次唤醒。短暂转头或遮挡合并为同一次相遇；自最后看见超过2秒模拟时间，再进入才算新相遇。判断仅基于该居民实际可见记录，不查询被遮挡人物的新位置。

每句讲话以一次speak动作标识。只在该听者首次实际听到片段时唤醒一次；听清程度变化、后续片段、提到名字或最后一片都不再重复。每位听者独立去重；未听到的内容不进入上下文，不提前发送完整台词。若只听到开头，居民可自主listen，也可沉默并continue现有动作。没有硬编码回答、自动问候或规则替代模型。

身体不适、动作失败、计划结束和居民自己设置的模拟时间复查仍可请求认知，所以不是“除说话外永不思考”。任何认知批次仍全局冻结，完整提交后恢复；观察者界面与网络继续，不补跑墙钟等待。
