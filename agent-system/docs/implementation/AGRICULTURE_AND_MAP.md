# 种植、畜牧与大地图

## 使用

右上「规划 / 区域」保留采集、制作、居住区，新增种植区与畜牧区。选择品种，再到地图单指拖出矩形、确认；双指继续平移和缩放。

- 居住区至少6×6格，种植与畜牧至少4×4格。不同用途不能重叠；同类可覆盖，已划范围不重复播种或添加动物，新覆盖的空地可扩展。已有树石、设施与池塘需要避开。
- 区域标记默认隐藏，右上「区域：开/关」可切换。圈地期间自动显示，完成或取消后恢复偏好。住宅淡紫、种植淡绿、畜牧淡金，只有薄边线和轻填色；主地图与小地图同步。偏好仅存本机，不修改模拟世界或存档。
- 种植可选水稻、小麦、玉米、胡萝卜。确认后播种，每区最多36片；水稻有浅水田，其他作物有土垄。幼苗逐步长大，谷物结穗并变金黄。点击作物查看生长进度和收割状态。
- 畜牧可选鸡、鸭、鹅或混养，每区最多9只。家禽在本区内确定性移动，切换散步、低头啄食、休息与扑翅；不同品种有相应外形。此版畜牧提供放养与活动，尚无产蛋、繁殖、屠宰或饲料消耗。
- 地图从56×56扩大到96×96；初始及「回营地」视野从20拉远至32，仍可缩放和旋转。地形、小地图、私人地图与圈地区域共用边界。

## 生长与收获规则

| 作物 | 成熟所需模拟时间 | 每片食物 |
|---|---:|---:|
| 水稻 | 100秒 | 3 |
| 小麦 | 90秒 | 3 |
| 玉米 | 130秒 | 4 |
| 胡萝卜 | 75秒 | 2 |

播种与成熟不直接增加仓储。成熟作物须被居民实际发现、走近采集，食物进入随身资源，再搬运到公告板仓储。当地食物不足时，本地规划优先处理本人已观察到的成熟作物；远程模型继续通过私人感知与既有采集动作选择目标。没有全图资源透视。收割完进入田茬阶段，12秒模拟时间后重新发苗；收割有短暂谷粒动画。

生长、摆动、走动、啄食与扑翅全部依赖模拟步。观察者暂停和认知等待均冻结，不按现实等待时间补跑。视图复用作物和动物网格，生长与移动不反复重建；几何与材质共享。旧存档缺少农业字段时照常恢复，新存档保存生长阶段、收割时间、动物姿态和后续随机阶段。

## 验证

- `tests/agriculture.test.ts`：四类作物成熟、实际采收、搬运入库、休耕与再生；区域重复与交叠规则；4000步家禽边界和确定性；本地规划实际收割与搬运、暂停冻结。
- `tests/agriculture-save.test.ts`：旧存档兼容、新状态往返、损坏字段拒绝、恢复后继续推进。
- `tests/agriculture-view.test.ts`：区域显示偏好、临时圈地、作物与家禽确认参数、暂停时重圈与默认视野。
- `tests/agriculture-mesh.test.ts`：作物与禽类姿态、同模拟时刻保持不变、共享资源生命周期。
- 地图、地形、小地图、私人记忆和居住交互测试覆盖新范围、边缘裁剪、索引上限与可见区域切换。
- `tools/verify-agriculture-ui.mjs`：实际Laya浏览器的桌面与手机布局、区域开关、作物阶段、禽类动作、暂停与节点复用，证据见 `evidence/agriculture-ui.json`。

新增界面字形由 `camp-extension.css` 内的Noto Sans CJK SC子集补齐，沿用项目已有SIL OFL许可。

浏览器使用本地构建及专用测试营地，无远程模型调用。该结果不等于微信真机或远程模型农业规划验收。
