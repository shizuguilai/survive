# 种植、畜牧与大地图

## 使用

右上「规划 / 区域」保留采集、制作、居住区，新增种植区与畜牧区。选择品种，再到地图单指拖出矩形、确认；双指继续平移和缩放。

- 居住区至少6×6格，种植与畜牧至少4×4格。不同用途不能重叠；同类可覆盖，已划范围不重复添加田块或动物，新覆盖的空地可扩展。已有树石、设施与池塘需要避开。
- 区域标记默认隐藏，右上「区域：开/关」可切换。圈地期间自动显示，完成或取消后恢复偏好。住宅淡紫、种植淡绿、畜牧淡金，只有薄边线和轻填色；主地图与小地图同步。偏好仅存本机，不修改模拟世界或存档。
- 种植可选水稻、小麦、玉米、胡萝卜。划区只预留荒地，每区最多36片。居民亲自翻土后才出现田垄，播种后才有种子，首次浇水后才发苗；水稻浇灌后呈浅水田，其他作物呈湿润土壤。幼苗逐步长大，谷物结穗并变金黄。点击田块查看待办步骤、生长进度、水分和收割状态。
- 畜牧可选鸡、鸭、鹅或混养，每区最多9只。家禽在本区内确定性移动，切换散步、低头啄食、休息与扑翅；不同品种有相应外形。此版畜牧提供放养与活动，尚无产蛋、繁殖、屠宰或饲料消耗。
- 地图从56×56扩大到96×96；初始及「回营地」视野从20拉远至32，仍可缩放和旋转。地形、小地图、私人地图与圈地区域共用边界。

## 自然田园外观

种植区的渲染以真实田块为基础，将相邻的已开垦地连成不规则田床，使用手绘泥土纹理与柔和边缘；较大的种植区分成几片连贯田床，之间留下窄路。取消原先每格独立方形土盒。作物叶簇、株距和朝向有固定的小幅差异，水稻、小麦、玉米和胡萝卜仍有各自轮廓及生长阶段。

未开垦的地块继续显示原有草地，装饰不会自动开垦、播种或提供产量。湿润效果来自实际浇水；点击、居民劳动与收割目标仍是原来那块田。田床为原生地面网格，旋转和缩放时保持地面一致，不使用整块农场截图遮盖场景。纹理来源及提示词见 `assets/art/garden-soil-provenance.json`（相对客户端目录）。

## 生长与收获规则

| 作物 | 成熟所需模拟时间 | 每片食物 |
|---|---:|---:|
| 水稻 | 100秒 | 3 |
| 小麦 | 90秒 | 3 |
| 玉米 | 130秒 | 4 |
| 胡萝卜 | 75秒 | 2 |

划定种植区不会凭空生成农作物。完整流程为：荒地 → 居民开垦 → 已翻土 → 居民播种 → 待浇灌 → 居民在池塘岸边取水、返回浇水 → 幼苗与生长 → 成熟 → 居民收割与搬运 → 田茬。田茬不会自动重新发苗，下一轮需要重新开垦、播种和浇水。

开垦需要5秒、播种3秒、浇水2秒、取水3秒，均为实际模拟时间；居民必须亲自走近对应田块或岸边。水桶最多6份，每次浇水消耗1份；水分随生长消耗，用尽后停止生长，补水才继续。上表成熟时间是累计有效生长时间，不包含开垦、往返和缺水等待。

播种与成熟不直接增加仓储。成熟作物须被居民实际发现、走近采集，食物进入随身资源，再搬运到公告板仓储。居民通过公告与私人观察了解耕作范围和状态，本地规划实际执行照料；真实模型可以调用相同的耕作、取水与采集动作。没有全图资源透视。

池塘水面与岸边安全距离加入真实移动碰撞，移动线段也做检查，防止大步长穿过水面。已知池塘参与绕岸寻路；目标为池塘时走到安全岸边，取水也在岸边完成。碰到未知池塘会产生私人受阻反馈，不提前知道远处障碍。旧存档中已站在水内的角色可以渐进走回岸边，不能继续横穿。

生长、摆动、走动、啄食与扑翅全部依赖模拟步。观察者暂停和认知等待均冻结，不按现实等待时间补跑。视图复用作物和动物网格，生长与移动不反复重建；几何与材质共享。旧存档缺少新字段时照常恢复，已种作物保留当前生长进度；新存档保存田块阶段、水分、水桶存水、动作执行进度、收割时间、动物姿态和后续随机阶段。

## 验证

- `tests/agriculture.test.ts`：划区不播种、开垦/播种/取水/浇水的真实动作、缺水停长、实际采收与搬运入库、收割后重新耕作；区域重复与交叠规则；家禽边界和确定性；本地规划实际收割与搬运、暂停冻结。
- `tests/pond-navigation.test.ts`：多方向穿越阻挡、已知池塘绕岸、岸边目标抵达和水中旧位置恢复。
- `tests/agriculture-save.test.ts`：旧存档兼容、新状态往返、损坏字段拒绝、恢复后继续推进。
- `tests/agriculture-view.test.ts`：区域显示偏好、临时圈地、作物与家禽确认参数、暂停时重圈与默认视野。
- `tests/agriculture-mesh.test.ts`：作物与禽类姿态、同模拟时刻保持不变、共享资源生命周期。
- `tests/garden-ground.test.ts`：自然田床几何、未开垦地保留、地面缓存与资源释放。
- 地图、地形、小地图、私人记忆和居住交互测试覆盖新范围、边缘裁剪、索引上限与可见区域切换。
- `tools/verify-agriculture-ui.mjs`：实际Laya浏览器的桌面与手机布局、区域开关、实际耕作流程、池塘通行、作物阶段、禽类动作、暂停与节点复用，证据见 `evidence/agriculture-ui.json`。
- `tools/verify-garden-ui.mjs`：专用视觉夹具检查连片田床、四种作物、桌面/手机、缩放/旋转及逐块选取；该夹具直接设定阶段，仅验证渲染，不作为真实农事流程证据。

新增界面字形由 `camp-extension.css` 内的Noto Sans CJK SC子集补齐，沿用项目已有SIL OFL许可。

浏览器使用本地构建及专用测试营地，无远程模型调用。该结果不等于微信真机或远程模型农业规划验收。
