# 地图记忆、文字记忆与原地行走修复

## 使用方式

左侧「地图记忆 · 个人探索」打开当前居民的地图，可切换阿林和小禾。「文字记忆 / 档案」进入该居民的私人记忆列表；原有历史翻页、阶段总结、关键进展仍保留。

地图以本人起点为原点，每格约2米。显示亲自走过的路线、曾看见的区域、亲眼辨认过的资源/设施、障碍和人的最后已知位置。暗色是未知，灰绿是曾看见，浅绿是走过，棕色是记得的障碍，黄线是近期路线。地标可能过时；居民不在场时发生的资源耗尽、移动等变化不会偷偷更新他的地图。

文字仍保存对话、约定、实际行动结果和重要经历。普通方向、距离变化更新感官与地图，不反复写成文字记忆，也不自行触发新认知；人物进入和讲话沿用前一轮去重规则。每名居民的模型只收到自己的两类记忆。观察者切换地图只读数据，不改变世界或为居民补充知识。

## 已复现的循环原因

测试夹具复现：居民距树2米时辨认出树，走到0.8米附近后受垂直视角影响只见模糊轮廓。旧逻辑把已辨认描述覆盖掉，而且重复walk到当前位置仍返回成功，3次零位移被写成3条移动完成。

现保留本人此前真正辨认过的描述，并说明当前视野模糊/信息过时。knownTargets标记是否已到最后已知位置附近。网关拒绝开头的原地walk，请真实模型重新选择；运行时若仍遇到原地walk，则给出诚实的行动失败，不记成移动成功。工程不会自动替模型选择采集或其他动作。

第一次接入地图后的真实测试出现行动参数校验失败（保留在memory-map-real-first-attempt.json）。补充按已知op返回具体安全字段错误、短计划格式指导，仍使用原来的真实模型纠错流程；不输出错误参数值，不放宽协议，不用规则补动作。

## 数据和边界

- 私人地图最多256格、64个路线点、64个地标；按近期观测/经过保留。它是有限粗略记忆，不是实时全图。
- 可见地面通过本人视距、水平/垂直视角和墙体遮挡采样；地标仅在亲眼辨认后写入。碰撞也能留下障碍记忆。
- 地图与文字记忆进入世界快照和回放；认知期间均冻结。读取界面不停，完整批次提交后恢复，不补等待时间。
- 行动目前仍以本人已知引用为目标，尚未实现自由坐标探索、完整绕障寻路器或记忆地图编辑。
- 此次改变模拟状态与行动结算，SIM_VERSION升至0.3.3；旧版本模拟回放不能当成本版重演验收。文字历史档案仍保留。完整现场存档恢复仍由T18跟踪，本轮未实现刷新后恢复整个正在运行的世界。
