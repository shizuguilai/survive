# 三种运行模式与阶段统筹（v0.4.0）

本轮依据用户新要求新增统一决策者和本地算法，调整了此前“所有模式只能独立真实模型、禁止任何算法替代”的适用范围。**独立居民模式继续保持原规则**；统筹和本地模式明确采用阶段任务执行器，不冒充独立居民思考。

## 使用

右上「运行设置」选择模式，默认「模型统筹」、4人、阶段4份材料、模型最短间隔30模拟秒、统筹失败自动转本地开启。点击「规划 / 建房」布置任务，点击「开始运行」启动。

| 模式 | 谁决策 | 执行与失败行为 |
|---|---|---|
| 模型统筹（默认） | 一个真实glm-4.5-air分配全体居民的阶段目标 | 本地执行器连续完成阅读、移动、取材、入库、制作、建造；阶段统一复查。远程失败按开关转本地或保持暂停 |
| 独立居民 | 每名居民独立请求真实glm-4.5-air | 只读自己的有限感官、地图和文字记忆；保留原触发规则；失败保持暂停，可手动切换模式 |
| 本地算法 | 确定性任务规划算法 | 不请求远程模型、不需要密钥；优先新任务，自行执行备料、加工和施工，明确标为LOCAL_ALGORITHM |

可配置2/4/6名居民、4/8份阶段工作量、30/60/120模拟秒的最短模型调用间隔。应用设置保留现场、任务和私人记忆；人数只在明确点击「新营地（重置）」后生效。左上「下一位」和地图窗口「下一位」支持查看更多居民。

## 分层决策与私有记忆

统筹模型每次接收公开任务、公共库存，以及按居民分开的有限汇报（身体、当前工作、最近4条行动结果、最多16个已辨认地标描述）。不发送整个World、私人信念库或全局地图，也不把甲的记忆写到乙那里。模型只从给各人的目标选项中分配一项目标。

执行器将阶段目标分解成原有的实际动作：靠近公告板并阅读、接受任务、靠本人地图认资源、行走采集、实际入库、走到地块分步施工。初始不赠送材料；配方要亲读；物资要真实扣除；各人的行动结果继续进入本人文字记忆。公共任务/库存属于此模式下的指挥信息，独立模式的上下文未加入这些全局信息。

一份阶段安排会持续覆盖多个执行节点，通常是若干份资源、一道施工步骤或一件工具。一般感官变化和动作中途不再触发远程请求。全体阶段完成、新任务、持续受阻/阶段超过120秒后，在最短调用间隔允许时统一复查。提前完成者可能等到复查间隔，界面会显示倒计时。途中身体自理由明确的执行器处理。

真实统筹请求使用短JSON目标列表、900输出token上限、25秒超时（全部纠错共用超时），不逐个生成长动作链。最多一次格式纠正，不生成规则伪造的模型答复。

任何实际认知请求仍先取得全局暂停锁；网络、界面继续；整批校验和提交后恢复，不补跑等待时间。批次缺人、错误来源、过期响应或停止后的迟到响应均不能提交。统筹失败自动降级时保留世界，显示持续提示，并把后续来源标为本地算法；不会每个执行节点反复重试坏网络。需要恢复远程时在设置中点击「重新尝试远程统筹」。

## 性能与来源记录

- 即时回放由不断积累改为最近600帧（约30秒）的滚动窗口，保留来源锚点；文字历史仍单独保存最近2000条。回放不调用模型。
- 观察者感官DTO按真实世界revision缓存，模型等待期间不反复计算；统筹/本地的continue不重复刷计划事件。
- 档案与回放区分REAL_MODEL（独立真实决定）、MODEL_DIRECTED（模型阶段安排下的执行器）、LOCAL_ALGORITHM（算法）、MOCK_TEST（测试）。不把33次执行器批次说成33次真实模型调用。
- 模拟版本升至0.4.0；旧模拟回放版本不兼容，文字档案保留。长时全场景性能和微信真机未验收。
