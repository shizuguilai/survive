# 营地美术与高清渲染（ART01）

本轮按用户要求参考《环世界》的俯视殖民地视觉方向：哑光色块、清楚轮廓、圆头短身居民、木石材质和深色观察界面。全部场景仍由 Laya 原生几何生成，没有复制游戏贴图或引入网页游戏框架。

## 改动

- 启用 Retina 画布与支持设备上的 4x MSAA。此前设计画布一直是1280×720，桌面放大与手机高密度屏会变糊；现在按实际显示像素生成。未加入模糊后处理。
- 俯视正交镜头改为轴向对齐，默认垂直视野26→18，缩放范围9–48。人物占屏更大，仍可拖镜头/缩放。
- 圆头比例加大、身体缩短加宽，人物轮廓描边，接地阴影；发型、胡须、衣服、帽子、手持石斧/石锄/武器与背包继续随真实装备变化。居民原本就穿衣，自主换装规则未改。
- 草地、泥路、干土细节和公告板铺石合为一个顶点色网格，不每帧生成，也不为每个地块增加独立场景节点。纹理变化由渲染坐标生成，不消费模拟随机数。
- 树冠分层、岩石明暗切面、池塘深浅水层、工作台板缝、房屋石基/横木/窗框/瓦缝/烟囱。施工阶段仍跟随buildStage，不提前展示竣工。
- 深灰界面、暖白文字、橄榄色按钮；居民名字描边，简短设施标签放在地面附近并避开居民。原生按钮、感官图层、私人地图、档案与运行设置保留。
