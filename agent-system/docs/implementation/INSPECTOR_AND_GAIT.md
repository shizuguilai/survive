# 可折叠居民信息与模拟步态（ART02）

## 操作与画面

进入页面默认收起左栏。左上「居民名 · 信息 ›」展开，再点「‹ 收起信息」关闭。每次新进入页面默认收起，不写入游戏存档。

收起后相机和地图触控范围同步从988扩展到1280设计像素（可见宽度增加29.6%），没有留一块空白来占位置。底部「档案 / 地图 / 感官」保留快捷访问；在场景中点居民仍可选中，名字出现在信息按钮。规划、工作台、地图、档案、运行设置根据可见地图区域居中。展开时完整保留健康、饥饿、疲劳、感知、意图和装备。

人物改为平涂材质、扁一些的头身轮廓和更明显的圆手，保留描边与轻微体积结构；树冠、灌木和岩石分色处理，地块色差收敛，弱化塑料球和棋盘格感。仍是原生Laya 3D，未复制《环世界》资产，也没有改引擎。

## 步态与时间边界

- 当前正在执行的walk动作产生左右交替的手臂摆动和轻微身体起伏；跑步频率较高。
- 刀、石斧、石锄属于对应手部节点，随手运动；双手长矛使用共同握持位移，双手不会反向扯开武器。
- 姿势只由当前动作的elapsedTicks与50ms固定模拟步长计算，不用Date、performance、Laya计时器或墙钟驱动动画。渲染帧只读取姿势。
- 认知冻结、玩家暂停或回放暂停保持同一姿势；恢复只随下一个模拟步推进，不补等待期间的动画。回放跳回同一个动作进度得到同一姿势。
- 等待、未开始、后续阶段、已完成行走或居民倒下均不原地摆手。影子留在地面，不随身体起伏抬起。
- 世界、私人地图/文字记忆、碰撞、动作结果、真实模型与三种控制模式没有被渲染逻辑修改。
