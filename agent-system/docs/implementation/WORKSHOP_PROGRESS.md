# 居民档案、工作台与小屋 v0.3

## 用户可见变化

1. 左侧「历史 / 档案」及居民姓名可打开记录。支持按实际行动、模型计划、发声、私人记忆筛选，翻页和条目详情；可切换之前轮次。自动保留本机最近2000条，保存失败明确提示。仅观察者使用，不进入居民上下文。回放只展示当前模拟时刻以前的历史。
2. 「工作台配方」展示明确投入与产出。石斧=2木材+3石料；石锄=2木材+2石料。居民先亲自read_notice学配方，用craft制造，再自行equip_item持握；合成不凭空装备。石斧伐木、石锄采浆果每份0.6秒，徒手1秒。工具不足收纳空间、材料不足或不在工作台附近时都不扣料。
3. 资源置换：3木材换2石料，3石料换2木材，2木材换2浆果；只消耗本人随身资源。公共仓储可haul存入、withdraw领取。加工与建造每3经验升一级，每级耗时减少4%，最高5级。采集经验记录熟练等级，不额外宣称采集等级加速。
4. 「规划 / 建房」可发采集、制作和木石小屋项目。三个预设地块可选，每块最多一座。地基2木材4石料、墙体8木材2石料、屋顶2木材2石料，总12木材8石料。施工在地块进行，完成时直接扣公共仓储，不必先withdraw取出。缺材料、步骤错序、他人已完成同一步时明确失败；不会重复扣款。
5. 原生Laya地图采用林地、采石区、浆果区和池塘的分区布局；公告板、仓储木箱、工作台与房屋的地基/墙体/屋顶可见。居民石斧和石锄有独立持握模型。房屋建成后门廊休息恢复加快。

## 保持不变的核心要求

每位居民独立调用指定glm-4.5-air，只获得自己的有限感官、私人记忆和已知引用。具体配方与任务在世界内亲自读取才进入知识；他人背包和观察者历史不进入输入。角色穿脱、取料、制作、施工和参与目标都由模型决定，没有规则代理或Mock兜底。

认知请求、重试和提交期间全世界冻结，网络与界面继续。规划操作只进入世界外队列，完整批次提交后的下一模拟步写入。生命、饥饿、物资、施工与技能经验都不补跑等待时间。模拟版本为0.3.0，旧回放仍保留，但不强行跨版本执行。

## 已修复问题与剩余范围

实测发现任务引用与公告板实体容易混淆；已分别说明可用动作，错误时不再笼统报告距离不足。已读仓储快照写入本人记忆，避免随后视线扫描将它覆盖。建房材料说明明确为直接扣公共仓储，与工作台的随身消耗区分。历史失败和复测范围在真实统计中保留。

小屋目前是简化单一蓝图，三个固定地块，并非任意画区域、房间编辑、室内碰撞或住房舒适度系统。没有居民间交易谈判、材料预留、正式承诺账本、救援或完整现场恢复。公开Web可玩不等于微信发布；缺LayaAir IDE实测、微信AppID/鉴权/合法域名与真机条件，任务板仍逐项标为partial或阻塞。
