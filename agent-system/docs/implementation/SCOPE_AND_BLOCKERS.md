# 本轮范围与阻塞

本轮优先范围为两名居民、两棵树、一堵墙：有限感官、个人记忆、独立真实模型请求、全世界认知屏障、真实发声与接收、原生 Laya 观察界面和按模拟时间回放。逐项代码、Mock、真实模型、构建、浏览器、真机和发布状态以主交付记录为准。

## 必须保持的行为

任何居民需要模型思考时，整个模拟暂停。网络、重试、存储和观察者镜头/界面继续运行。完整决策批次验证并提交后才恢复；失败保持暂停，不用规则或 Mock 自动替居民决定。等待期间的真实时间不能计入身体、环境或回放，也不得恢复后补跑。

各居民请求只含本人有限感官、已知目标、私人记忆和本人可操作物品引用。装备的模型引用为居民局部 `item_1` 等，内部全局 ID 与他人包内物品不进入私人输入。观察者感官开关只改变显示，不改变感知计算。

居民初始化就穿衣，后续穿脱、持拿和收纳由居民自己的模型决定，没有玩家换装入口。相关动作按正模拟时长执行；双手武器占用双手，更换/卸下背包若容量不足则整次拒绝并保留全部物品。武器目前仅有造型、持拿与槽位规则，没有攻击、伤害或战斗系统。

## 验证边界

- 单元测试中的 `Mock` 只用于屏障、感官隔离、错误处理、装备和回放等工程验证。
- 正常客户端要求 `REAL_MODEL` 响应；当前真实服务认证失败时保留可观察的静止世界，不生成假对话。
- `npm run build` 是 TypeScript 检查与 Web 打包，不是 LayaAir IDE 或微信发布构建。
- 原生网格使用替身 API 的资源生命周期测试不是真浏览器图像验收。
- 已导出的回放按已有事件播放，不重新请求模型；回放可读取与“恢复现场模拟继续决策”是不同能力。
- 推送代码、部署 Web 服务、微信真机通过和微信正式发布分别记录，不相互代替。
