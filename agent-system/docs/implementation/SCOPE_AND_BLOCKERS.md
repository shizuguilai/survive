## 必须保持的行为

任何居民需要模型思考时，全世界模拟暂停；网络、重试、存储和观察界面继续。完整批次验证并提交后恢复，失败时保持暂停，不以规则或Mock生成决定，不补跑等待时长。

每名居民只获得本人的有限感官、私人记忆和已知引用。本人装备引用是局部 `item_1` 等；内部全局ID和他人包内物品不进入输入。观察者感官开关只改变显示。

网关提示明确continue和私人记忆evidence格式，按该居民allowedActions过滤schema。`thinking disabled` 与 `max_tokens=4096` 是指定真实模型支持的请求配置，用于减少时延；无效决定仍拒绝，工程不改写模型动作。

居民初始化就穿衣，穿脱与持拿由本人模型决定，按正模拟时长执行；双手占位、归属和容量受校验。武器目前只有外观和持拿，没有攻击或伤害实现。本轮真实工具制作/持握单独验收；普通衣物自主换装尚待专项实测。
