# 触控、观察详情与自主住宅（2026-09-28）

沿用 LayaAir 3.3.12 + TypeScript、现有 glm-4.5-air / 本地模式、独立感知与全局认知屏障。没有恢复后台回放采集。

## 使用

- 单指拖动地图，双指同向平移、张合缩放；围绕两指中点保持观察位置，加减按钮与滚轮继续可用。两指结束后等待全部手指松开，不接续单指拖动，也不误选人。现已加入小地图和镜头边界，详见 [地图导航](MAP_NAVIGATION.md)。
- 右侧「仓储」显示真正入库的木材、石料与食物，支持折叠。不累计角色背包或地上的剩余资源。
- 点击人物直接展开详情，分为「身体与心情」「随身携带」「心愿与活动」。图标和状态条显示生命、饱腹感、心情、精力；「查看物品」列出资源、已装备及包内物品。心情是缓慢变化的模拟状态，受温饱、疲劳、疼痛和拥有住处影响。
- 重叠角色可以重复点击轮选，也可用「下一位」。展开侧栏时维持点击处的地图锚点，减少镜头跳变。
- 点击树木、岩石、浆果显示初始总量、剩余量及采集阶段。每25%一个外观阶段；岩石缩小、树冠减少/出现切口/倾斜，采空留下碎石或树桩。只跨阶段重建网格，避免每帧重新建模。
- 「规划 / 居住区」→「划居住区」→在地图拖出范围→「确认居住区」。可自由选择矩形的位置和大小，最小6×6格，最多8区。界面给出当前可用住宅空地数；有树石/池塘/建筑占用时会避让，没有空地时不会覆盖它们。可以增加其他区域。
- 居民亲自阅读居住公告，再通过既有 accept_task 自主申请自己的地块。各自有一项独立建房任务，仍需采集、入库、分阶段施工；同一居民已有房屋或在建房时不重复申请。一片区不会因第一间房竣工就结束。
- 屋顶显示开关在右上角，仅改变观察画面，本机保存偏好。物理墙与感官遮挡继续存在。门口留有通道，已知住宅使用绕墙、经门的路线；不知道的障碍实际接触后反馈受阻，不向模型传入全地图路线。
- 人物在地板上行走不再沉入地基；新墙建成时把恰好站在墙体里的身体移到最近合法位置。建造、采集、加工有双手动作，动作相位仅取模拟时间，暂停和模型等待时保持冻结。

## 关键代码

- `apps/laya-client/src/view.ts`、`interaction.ts`、`hud-icons.ts`：手势、点击、分区面板、圈选和屋顶控制。
- `world-mesh.ts`、`pawn-pose.ts`、`character-mesh.ts`：资源阶段、屋顶部件及模拟驱动工作动作。
- `packages/sim-core/src/housing.ts`、`camp.ts`、`colony.ts`：圈地校验、空地检查、个人房屋申请和阶段执行。
- `navigation.ts`、`actions.ts`、`workshop.ts`、`perception.ts`：与模型一致的墙体、门口路线、地板高度及视线遮挡。
- `tests/settlement-interaction.test.ts`、`tests/touch-handlers.test.ts`、`tools/verify-residential.ts`：可复现验证。

矩形圈地目前不支持删除/改形。住宅从4×3小屋开始，现已增加居民自主拆旧扩建与家具，详见 [生活系统](LIVING_SYSTEM.md)；居民仍不能通过观察者小地图获得全图资源信息。既有旧地块接口仅保留兼容测试和旧记录，玩家界面不再使用三个预设选项。
