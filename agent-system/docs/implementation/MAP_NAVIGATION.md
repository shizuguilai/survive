# 小地图与稳定触控（2026-09-29）

沿用 LayaAir 3.3.12 + TypeScript。此轮只改变观察导航和界面，不改变居民决策、私人记忆或模拟时间。

## 操作

- 右下「营地小地图」显示整片地形、资源位置、住宅、居住区、居民和浅黄色视野框；被选中的居民为蓝点并带白圈。
- 点击或用一指拖动小地图可以移动镜头。「回营地」回到公告板附近并恢复常用视距；标题栏的减号可收起小地图。
- 两指同向移动平移镜头，两指距离明显变化才缩放；小幅指距抖动不会导致平移时忽大忽小。缩放以两指中点对应的地面位置为锚点。
- 松开其中一指后等待所有手指离开，不将余下手指接成拖动或点击人物。第三指不会替换原来的手势配对。
- 普通单指拖动、点击选人、加减按钮和鼠标滚轮继续可用；圈选居住区时，单指圈地，双指调整镜头。
- 镜头移动和缩放都受到地形边界约束；侧栏切换和尺寸变化也重新检查边界。最远视距按可用画幅调整，防止露出地形外的灰色背景；完整地图可在小地图查看。

## 问题与修正

旧版从 `Camera.worldToViewportPoint` 的投影结果反算地面坐标。当前随项目使用的 Laya 引擎实现直接读取缓存视图矩阵，并将返回的舞台坐标取整；同一渲染帧中连续修改镜头后，输入事件可能仍读到上一次的投影，从而反复叠加偏移。

此轮按固定正交镜头的位置、倾角和画幅直接计算全精度坐标，不依赖上一帧矩阵。Laya 会逐个更新 `changedTouches` 并发出移动事件；双指状态先保存，在观察画面的下一帧合并应用，避免第一根手指的新位置与第二根手指的旧位置组合出虚假的捏合。边界处重置锚点，反向移动立即响应。

小地图使用原生 Laya Sprite / Text / Graphics。导航只修改观察镜头，暂停或等待模型时仍可使用；不推进世界、不写入居民地图记忆。资源图层、居民点和视野框分别缓存，避免没有变化时重绘。
