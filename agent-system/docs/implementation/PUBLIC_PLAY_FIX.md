# 公开试玩启动修复

原因：站点公开后，Worker仍强制要求私有站点身份，客户端无登录入口。

修复：服务端显式设置SURVIVE_PUBLIC_PLAY=true允许匿名启动，health独立返回canStart，不伪造authenticated。默认关闭公开试玩，私有身份检查仍保留。同源、JSON体积、居民上下文契约、固定glm-4.5-air、并发上限及失败全局暂停不变。密钥仅存服务端。

验证：代码完成；10项网关及Worker测试通过（Mock与权限测试，不冒充新增真实模型验收）；TypeScript通过。真实模型闭环沿用上一版10次真实决策证据；本修复的线上实时浏览器和微信真机未验收。构建及发布以Sites部署记录为准。
