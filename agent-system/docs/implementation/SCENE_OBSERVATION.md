# 地标、旋转与场景细节（2026-09-29）

## 使用变化

- 公告板、仓储和建筑标签固定在各自的世界坐标锚点；居民经过时不再自动下移避让。镜头平移或旋转时，标签仍跟随所属物体。
- 缩放按钮下方增加「左转 / 复位 / 右转」。每次转45°，绕当前观察中心旋转；复位只恢复原始朝向。配合现有「屋顶：隐藏」可从不同方向看房内家具。
- 旋转统一应用到投影、人物/物体点击、单指移动、双指平移与缩放、居住区圈选、边界限制及小地图。地图旋转不会改变模拟世界或居民私人记忆。小地图本身保持固定朝向，视野以旋转矩形显示。
- 树木阴影随采伐阶段收缩；采空后只保留树墩脚下的小阴影和截面。树木倾斜仅作用于树干树冠，阴影保持贴地。
- 灯具改为底座、立杆、金属框、透明玻璃灯罩、锥形顶罩和灯芯；夜间灯芯呈暖色。移除原来地板上的实心圆形光斑。这是灯具外观与发光材质，没有增加动态点光源。
- 「已发布的目标」支持单指滑动、鼠标滚轮和拖动滚动条，显示全部目标和完整说明，最新目标在上方；进度变化保留滚动偏移，不再只截取六项。

## 验证范围

- TypeScript 和 Web 构建由发布流程检查；构建摘要见 `evidence/web-build.json`。
- 16项针对性检查通过：8种朝向与两种侧栏画幅的坐标转换/边界/捏合锚点、真实视图处理器的旋转和平移、视野多边形更新、重叠选择、固定地标、20条目标完整展示与滚动位置、原生滚动事件、树墩阴影尺寸与树干倾斜隔离、灯具部件与昼夜/屋顶开关。
- 完整检查输出见 `evidence/scene-observation-tests.txt`。
- 渲染结构通过原生对象测试夹具检查，当前未进行实际浏览器画面或手机实机验证；不能将这些检查视作真机验收。
- 本轮没有修改模拟推进、模型调用、家具成本、房屋碰撞或灯具的生活效果。
