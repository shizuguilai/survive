# 频繁思考与动作停顿修复 v0.3.1

此文记录v0.3.1历史验收。人物辨识变化和语音末片再次触发已被[v0.3.2规则](ENCOUNTER_TRIGGERS.md)替代。

## 查到的问题

每200毫秒进行一次视野扫描，旧实现将所有相对方向、距离档位和背景进出视野都当成必须立即重新决策的事件。显式单居民移动夹具在3.25秒模拟时间内请求11次，每次真实请求又全局冻结，动作可见时间极短。讲话每四个字的片段也会立即触发听者重新决策，进一步增加停顿。

本次读取的近期托管日志只见健康检查和favicon请求，没有捕获该用户这一轮模型请求的完整链路，不能据此断言其手机会话没有超时。现在服务端增加脱敏的request_started/completed日志；客户端显示等待对象、批次返回进度、累计等待时间、重试次数和正在执行的真实动作。

## 处理方式

感官仍按原频率更新观察和私人记忆。执行已有模型动作时，普通背景视差不再直接唤醒认知；新人物、人物辨识/外观变化、任务目标明确变化、模型显式关注的视觉事件仍可唤醒。普通背景新信息会在计划完成或模型设定复查时进入下一次判断。程序不替居民选择行动。

语音仍按实际发声片段传播，首次听清与末片触发复查；中间片段持续写入听觉，不提前泄露剩余台词。听见自己名字的显式关注、身体不适和行动失败保持及时触发。只调整何时需要重新认知；一旦认知开始，全世界仍冻结，网络、状态显示和观察界面继续，完整批次提交才恢复，不补跑等待。
