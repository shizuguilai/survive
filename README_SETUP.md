# Project Outpost 安装与运行指南

末日营地（Project Outpost）是代码驱动的 Cocos Creator 3.8 项目：
场景里只需挂一个 `GameRoot` 脚本，地图 / 角色 / UI 全部由代码生成。

---

## 一、准备

1. 安装 Cocos Dashboard 与 Cocos Creator 3.8.x（建议 3.8.6）。
2. 本目录 `project_outpost/` 已包含全部脚本（`assets/scripts/`）与工程配置。

## 二、打开项目（任选其一）

### 方式 A（推荐，最稳）：新建项目 + 拷贝脚本
1. Cocos Dashboard → 新建项目 → 选 **Empty (2D)** 空模板，位置随意（路径请用英文）。
2. 关闭编辑器，把本目录的 `assets/scripts` 整个文件夹复制到 **你新项目的 `assets/` 下**。
3. 重新打开项目，编辑器会自动导入脚本并生成 `.meta`。

### 方式 B：直接打开本目录
- Cocos Dashboard → 打开项目 → 选择 `project_outpost` 文件夹。
- 若提示不是有效项目，请改用方式 A。

## 三、场景设置（唯一需要手动操作的一步）

1. 新建场景：在 `assets` 里右键 → 新建 → Scene，命名 `Main`，双击打开。
2. 场景里默认有 `Canvas`（含 Camera）。右键 `Canvas` → 创建 → 空节点，重命名为 `GameRoot`。
3. 选中 `GameRoot` 节点 → 右侧 Inspector → 添加组件 → 搜索 `GameRoot` → 添加。
4. Ctrl+S 保存场景。

## 四、运行预览

- 点击编辑器顶部的「在浏览器预览」按钮。
- 预期看到：彩色瓦片地图（草地/森林/石头/水/废墟/道路）、几个蓝色幸存者在采集、顶部资源栏、左侧建筑菜单、右下变速按钮。
- 操作：
  - 单指拖动 = 平移地图；双指 = 缩放。
  - 点左侧建筑按钮选择建筑 → 点地图空地放置（消耗资源，工人会自动来建造）。
  - 右下 `II / 1x / 2x / 3x` = 暂停 / 变速。

## 五、各里程碑自测要点

- M0 地图：能拖动、缩放，地形颜色正确。
- M1 资源/HUD：顶部资源数随采集增长，幸存者会动。
- M2 采集：伐木工往返森林与仓库，木材增加；工人无工地时采石。
- M3 建造：放置建筑出现灰色工地 → 工人到场 → 进度满变为成品。
- M4 人口：粮食充足且住房够（建帐篷/房屋）时，约每 120 秒新增 1 人。
- M5 尸潮：第 2 天起边缘刷红色僵尸，攻击建筑；建兵营后可出士兵（见下）、瞭望塔自动攻击。
- M6 存档：刷新页面后进度保留（localStorage 自动存档，每 15 秒）。

> 说明：士兵/狙击手职业需要先建「兵营」。当前版本初始幸存者职业为伐木/工人/拾荒，
> 手动改职业的 UI 计划在后续迭代加入；如需测试战斗，可临时在 `World.init()` 里把某个
> 幸存者的 `job` 设为 `JobType.Soldier`。

## 六、发布到抖音小游戏（M7）

1. 菜单 → 项目 → 构建发布（Build）。
2. 发布平台选择 **抖音小游戏（ByteDance Mini Game）**。
3. 填写游戏名称（中文显示名，如「末日营地」）、AppID（测试号即可）。
4. 点击「构建」，完成后点「生成」/「运行」，会调起 **抖音开发者工具** 打开构建产物预览。
5. 在抖音开发者工具中用模拟器或扫码真机预览。

### 常见问题
- 预览黑屏：确认 `GameRoot` 组件已挂在 Canvas 下的节点上，且场景已保存。
- 中文/资源路径报错：确保项目路径为纯英文（本项目即为此目的取名 `project_outpost`）。
- 触摸点击位置不准：不同分辨率下若有偏差，反馈给我，需要校准坐标换算。
- 帧率低：高天数僵尸数量大时，实体渲染可由立即模式改为节点池（后续优化项）。
